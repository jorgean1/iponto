# Extensão Iponto para Chrome e Edge

Ela monitora os pontos confirmados pelo Iponto e recarrega automaticamente as abas abertas de `localhost:3077` e de `/Lancamentos`, mesmo sem foco.

## Instalar no Chrome

1. Extraia `Iponto-Extensao-Chrome.zip` para uma pasta permanente.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação** e selecione a pasta extraída que contém `manifest.json`.
5. Fixe a extensão Iponto na barra. Clique no ícone para conferir **Conectado ao Iponto**.

## Instalar no Edge

Use `edge://extensions`, habilite **Modo de desenvolvedor** e escolha **Carregar sem pacote**.

O Iponto precisa estar rodando em `http://localhost:3077`. Chrome para Android não aceita esta extensão; ela é destinada ao navegador do Windows.
